**DmWhatsapp** is a lightweight web-based tool to send WhatsApp messages **directly to any number** without saving it to your contacts list. Built using pure **HTML, CSS, and JavaScript**, this tool opens the WhatsApp Web chat for the number you enter.

## 📦 Installation

You can use this project locally or deploy it on your own server:

### Option 1: Clone from GitHub


git clone https://github.com/theofficialvkr/DmWhatsapp.git
cd DmWhatsapp

Then open index.html in your browser.

Option 2: Download ZIP

1. Go to https://github.com/theofficialvkr/DmWhatsapp

2. Click "Code > Download ZIP"

3. Extract and open index.html






🛠️ How It Works

The app generates a WhatsApp URL in the format:

https://wa.me/<phone_number>?text=<encoded_message>

Example:

https://wa.me/919876543210?text=Hello%20from%20DmWhatsapp!

When you click “Send Message”, it redirects you to WhatsApp (web or mobile) with your message pre-filled.


---

🔧 Usage Guide

1. Enter a valid phone number (with country code, e.g., +91XXXXXXXXXX)


2. Type your message in the box


3. Click "Send Message"


4. You’ll be redirected to WhatsApp Web or Mobile App with your message ready to send
